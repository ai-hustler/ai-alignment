How this works

Each game puts AI models from different makers in the same situation with something at stake, then lets them choose. Code and dice run the rules. The models write every word they say and make every choice.

Every game is played several times. For each one this site publishes the count of who did what, the exact prompts, the raw replies and the data files, so anyone can check the claims made in the videos.

Every line of model speech on these pages is unedited model output. The rules, the dice and the labels ("fibbed", "told the truth") come from the game's code, which compares each real score with the reported one. A handful of games shows what these players did in these games. It is not a measure of what any model usually does, and "lights out" here only ever means leaving a game.
